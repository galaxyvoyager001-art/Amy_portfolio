Craft · made by hand, read by eye
A HOUSE IN
MINIATURE
How much can a world hold when it is read only by the eye?
The tactile books asked how a story can be read by hand. This project asks the opposite. I shrank a whole home onto a desktop: a study, a dressing room, a living room behind a round moon window, a loft bed over the kitchen, and a dining table already set for dinner.
Three things that make it look real
Same scaleEvery object is made to one scale, so a teacup is the right size next to the chair. If one thing is off, the whole room looks fake.
Tiny partsThe smallest pieces are placed with tweezers and fixed with very little glue, so no glue shows.
Real materialsPaper for the walls, real fabric for the soft things, and a round moon window give each room its own feel.
