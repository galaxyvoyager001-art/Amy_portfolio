# Amy Hu · Portfolio

在线画布（Design canvas）：https://claude.ai/artifact/SfFHf2uV7uZGSP8qeGcVna

- 页面尺寸：**1920 × 960（2:1 宽幅跨页）**，参照老师给的优秀作品比例。
- 全英文。主题：**Made for the Senses**，五个板块分别对应一种感官。
- `portfolio/project/`：画布源文件，每页一个 `.dc.html`，`canvas.json` 是页面排布。
- `portfolio/assets/`：处理好的图片（抠图 `cut_*`、书页裁切 `page*`、修图后的照片）。
- 根目录的 `.docx` / `.pdf` 是原始素材。
