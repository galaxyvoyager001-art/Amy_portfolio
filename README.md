# Amy 作品集 · Portfolio

在线画布（Design canvas）：https://claude.ai/artifact/SfFHf2uV7uZGSP8qeGcVna

`portfolio/project/` 里是画布源文件：每页一个 `.dc.html`，`canvas.json` 是页面排布。
页面尺寸统一为 **A4 横版（1123 × 794 px）**，共 18 页，可以在画布里导出成 PDF。

## 页面结构

| 页码 | 文件 | 内容 |
|---|---|---|
| 01 | Main | 封面 |
| 02 | Contents | 目录 |

| 04 | Reading-Process | 手工书制作过程（6 步） |
| 05 | Reading-Workbench | 手工书工作台（俯拍 + 工具标注） |

## 素材清单

照片尽量用原图（手机原图即可，不要微信压缩过的），文字直接发给我即可。

### 基本信息
- 姓名拼写（英文 / 中文）、申请年份
- 一两句贯穿全书的自我介绍（目录页左下）

### 01 爱心伴读
- [ ] 标题页竖版大图：你和孩子一起读书（P03）
- [ ] 项目简介 2–3 句；角色、活动次数、做了几本书、陪伴了多少孩子（P03）
- [ ] 制作过程 6 张：选纸裁切 / 画插图 / 折页 / 打孔穿线 / 做封面 / 成品（P04）
- [ ] 每一步一句说明：纸张克重、装订方式等（P04）
- [ ] 工作台俯拍 1 张，从正上方拍整张桌面（P05）
- [ ] 你实际用到的工具名称（P05）
- [ ] 活动照片 5 张：全景、孩子拿书特写、互动、孩子的画或留言、合影（P06）
- [ ] 一句孩子说过的话；3 次活动记录：日期 / 地点 / 读的书 / 人数（P06）
- [ ] 展览照片 3 张：全景、展签或海报、观众翻书细节（P07）
- [ ] 展览名称、地点、日期、展出数量、一段感想（P07）

### 02 Craft 手工（白底）
- [ ] 7 件作品，**每件都在纯白背景上拍**：白纸或白布铺底，靠窗自然光，不开闪光灯
- [ ] 第 1 件（最得意的）多拍一张细节特写
- [ ] 每件：名称、材料、尺寸、年份

### 03 Baking 烘焙
- [ ] 手账页：成品照 1 张 + 切面 / 组织特写 1 张（P10）
- [ ] 一份配方：各原料克数（我会帮你算烘焙百分比）（P10）
- [ ] 物理性质数据：面团温度、烤箱温度、烤前 / 烤后质量、长高多少 mm、出炉中心温度；如果没测过，下次烤的时候可以补测（P10）
- [ ] 最好看的一张成品大图：侧逆光、浅景深、深色或木质背景（P11）
- [ ] 烘焙工作台俯拍 1 张 + 用到的工具（P11）

### 04 Music + Sports
- [ ] 音乐 2 张（演奏照 + 乐器或乐谱特写），乐器、等级、演出或比赛经历
- [ ] 运动 2 张（训练 + 比赛抓拍），项目、队伍、成绩

### 05 Academic Papers
每篇论文需要：
- [ ] 论文题目、作者 / 队友、指导老师、时间、获奖情况
- [ ] 摘要原文（英文）
- [ ] 1 张最能代表这篇论文的图（实验装置、数据图、模型示意图都可以）
- [ ] 一个关键结果（数字 + 单位）、方法、你本人负责的部分、3 个关键词
- [ ] 学术部分开头的一段研究兴趣介绍（80–120 词）
